振動モーター駆動回路 — ユニバーサル基板レイアウト

XIAO nRF52840 Sense / BSS138 ローサイドスイッチ / コイン型 ERM。座標 = 列1–12 × 行A–G。

基板配置図（部品面から見た図・XIAO は USB-C を左向きに挿す）

3V3 ネット GND ネット ドレイン / モーター ゲート（信号）

向き: USB-C を左・部品面を上にして挿すと、手前のソケット行（行F）が左から VUSB / GND / 3V3 / D10 / D9 / D8 / D7 になる。使うのは F2=GND・F3=3V3・F4=D10 の3つ。

配線リスト（この10本だけ）

#部品 / 種別始点終点メモ

ゲートで3本合流: F8（ゲート）に「R1（D10から）」「R2（GNDへ）」「BSS138ゲート足」が集まる。ここが配置の中心。R1 は行F上を D10→ゲートへ飛ばす（間の D9/D8/D7 は足を浮かせて跨ぐ、または裏配線）。

XIAO ピン参照（行F・手前ソケット）

F1VUSB
F2GND
F33V3
F4D10
F5D9
F6D8
F7D7

※列数・行数は実物のソケット位置に合わせて微調整すること。右側に空き列が4〜5列あれば足りる。BSS138 は変換基板ごと 2×4 穴（列8–9 × 行C–F）に挿す。ドレイン端（単脚側=2穴分岐）を上（行C）に、ゲート/ソース端を下（行F）に向ける。どの穴が G/S/D かはテスターで確定した通り。
